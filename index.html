AI & 머신러닝 종합 요약 & 중간고사 가이드

📌 1주차: 인공지능 기초 패러다임 & 학습 범주

1) AI vs 머신러닝(ML) vs 딥러닝(DL)

  • 규칙 기반 시스템 (Rule-based AI): 인간 전문가가 데이터의 논리 규칙(if-then)과 조건을 명시적으로 직접 코딩합니다. 데이터로부터 가중치를 스스로 갱신하는 학습 과정이 없습니다.
  • 머신러닝 (Machine Learning): 규칙을 직접 정의하지 않고, 대량의 데이터로부터 컴퓨터가 알고리즘을 통해 데이터의 규칙과 내부 파라미터(\(\mathbf{w}, b\))를 스스로 학습합니다.
  • 딥러닝 (Deep Learning): 머신러닝의 하위 분야로, 다층 인공신경망(ANN)을 기반으로 원시 데이터로부터 유의미한 특징(Feature Representation)을 계층적으로 자동 추출합니다.

2) 머신러닝 3대 학습 유형 비교

학습 패러다임 제공 데이터 구성 핵심 학습 목표 대표 작업 / 응용
지도학습 (Supervised) 입력 데이터 \(\mathbf{x}\) + 정답 레이블 \(y\) 입력에서 출력으로의 매핑 함수 \(f(\mathbf{x}) \approx y\) 학습 • 회귀(Regression): 연속적 수치 예측 (주택가, 기온)
• 분류(Classification): 이산적 클래스 예측 (숫자 0~9, 스팸 필터)
비지도학습 (Unsupervised) 정답 레이블 없음 (\(\mathbf{x}\)만 제공) 데이터의 내부 구조, 잠재적 패턴 및 분포 파악 군집화(Clustering), 차원 축소(PCA), 밀도 추정
강화학습 (Reinforcement) 환경 상태(\(S\)), 행동(\(A\)), 보상(\(R\)) 시행착오를 거치며 누적 보상(Reward)을 최대화하는 정책(Policy) 최적화 게임 AI (AlphaGo), 자율주행 제어

📌 2주차: 단일/다변수 선형회귀 & 경사하강법 최적화

1) 선형 가설 함수 (Hypothesis Function)

  • 단일 입력 변수 가설식: \(H(x) = wx + b\)
  • 다변수 가설식 (행렬 내적 형태): \(\mathbf{x} = [x_1, x_2, \dots, x_d]^T\), \(\mathbf{w} = [w_1, w_2, \dots, w_d]^T\) 일 때, \(H(\mathbf{x}) = \mathbf{w}^T \mathbf{x} + b = w_1 x_1 + w_2 x_2 + \dots + w_d x_d + b\)

2) 비용 함수 (Cost Function): 평균 제곱 오차 (MSE)

전체 데이터 수 \(n\)개에 대한 오차의 제곱 평균을 계산합니다:

\(k\text{cost}(\mathbf{w}, b) = \frac{1}{n} \sum_{i=1}^{n} \left( y_i - H(\mathbf{x}_i) \right)^2 = \frac{1}{n} \sum_{i=1}^{n} \left( y_i - (\mathbf{w}^T \mathbf{x}_i + b) \right)^2\)

3) 경사하강법 (Gradient Descent) 원리 & 파라미터 업데이트

손실 함수의 기울기(Gradient) 반대 방향으로 이동하여 최솟값을 탐색합니다 (\(\alpha\): 학습률, Learning Rate):

\(w_j \leftarrow w_j - \alpha \frac{\partial \text{cost}(\mathbf{w}, b)}{\partial w_j}, \quad b \leftarrow b - \alpha \frac{\partial \text{cost}(\mathbf{w}, b)}{\partial b}\)

4) 경사하강법의 세부 방식 비교

방식 1회 갱신 시 데이터 장점 단점
배치 경사하강법 (BGD) 전체 훈련 데이터셋 전부 기울기 방향이 정확하고 안정적으로 수렴 계산 시간 및 메모리 소모 극심, 속도 느림
확률적 경사하강법 (SGD) 무작위 데이터 단 1개 속도가 매우 빠르고 Local Minima 탈출에 유리 기울기 진동(Noise)이 심해 정확한 수렴 어려움
미니배치 (Mini-batch GD) 일정 크기의 묶음 (예: 32, 64, 128개) GPU 병렬 처리 최적화, 속도와 안정성의 완벽한 절충 배치 크기(Batch Size) 하이퍼파라미터 튜닝 필요

📌 3주차: 로지스틱 회귀 (Logistic Regression) & 손실함수

1) 로지스틱 회귀와 시그모이드(Sigmoid) 함수

선형 결합 \(z = \mathbf{w}^T \mathbf{x} + b\)의 연속적인 출력을 0과 1 사이의 확률값 \(P(y=1\vert{}\mathbf{x})\)으로 압축 변환합니다:

\(\sigma(z) = \frac{1}{1 + e^{-z}}, \quad H(\mathbf{x}) = \sigma(\mathbf{w}^T \mathbf{x} + b) = \frac{1}{1 + e^{-(\mathbf{w}^T \mathbf{x} + b)}}\)

2) 교차 엔트로피 손실 (Cross-Entropy Loss) 도입 이유

  • MSE 적용 시 한계: 비선형 함수인 Sigmoid에 MSE를 결합하면 손실 곡면이 비볼록(Non-convex) 형태가 되어 수많은 Local Minima에 갇히게 됩니다.
  • 교차 엔트로피(BCE) 도입: 손실 곡면을 볼록(Convex) 함수로 만들어 경사하강법 시 전역 최솟값(Global Minimum)으로의 안정적 수렴을 보장합니다.
\(\text{cost}(\mathbf{w}, b) = -\frac{1}{n} \sum_{i=1}^{n} \Big[ y_i \log(H(\mathbf{x}_i)) + (1 - y_i) \log(1 - H(\mathbf{x}_i)) \Big]\)
  • 실제 정답 \(y = 1\) 일 때: 손실은 \(-\log(H(\mathbf{x}))\) \(\rightarrow\) 예측값 \(H\)가 1이면 손실 0, 0에 가까워지면 손실 무한대 폭증
  • 실제 정답 \(y = 0\) 일 때: 손실은 \(-\log(1 - H(\mathbf{x}))\) \(\rightarrow\) 예측값 \(H\)가 0이면 손실 0, 1에 가까워지면 손실 무한대 폭증

📌 4주차: 인공신경망(ANN) 기초 & 활성화 함수

1) 뉴런의 연산 메커니즘 (Linear Combine + Activation)

인공신경망의 각 뉴런은 항상 다음 2단계를 연속으로 수행합니다:

  1. 가중합 선형 변환: \(z = \mathbf{w}^T \mathbf{x} + b = \sum_{j} w_j x_j + b\)
  2. 비선형 활성화 함수 통과: \(a = f(z)\) (신경망이 복잡한 비선형 결정 경계를 형성하게 만듦)

2) 핵심 활성화 함수 비교 & 기울기 소실(Vanishing Gradient)

함수명 수식 \(f(z)\) 출력 범위 장단점 및 특성
항등함수 (Identity) \(f(z) = z\) \((-\infty, \infty)\) 미분값이 항상 1 (\(f'=1\)). 과제 7~9번 손계산 문제의 활성화 함수로 채택.
Sigmoid \(\frac{1}{1 + e^{-z}}\) \((0, 1)\) 이진 분류 출력층에 필수적이나, \(\vert{}z\vert{}\)가 클 때 기울기가 0으로 수렴하는 기울기 소실(Vanishing Gradient) 유발.
Tanh \(\frac{e^z - e^{-z}}{e^z + e^{-z}}\) \((-1, 1)\) 원점(0) 중심 대칭이라 Sigmoid보다 학습 수렴이 우수하나 여전히 깊은 층에서 기울기 소실 존재.
ReLU \(\max(0, z)\) \([0, \infty)\) \(z>0\)에서 미분값이 1로 유지되어 기울기 소실 문제를 극복, 연산 속도가 매우 빨라 은닉층의 표준으로 채택.
Softmax \(\frac{e^{z_k}}{\sum_{j} e^{z_j}}\) \((0, 1)\), 합 1 다중 클래스 분류의 최종 출력층에서 각 클래스에 대한 예측 확률 분포를 생성.

📌 5주차: 신경망 역전파 (Backpropagation) & 연쇄법칙

1) 2-2-2 MLP 기본 세팅

  • 입력: \(x_1, x_2\) | 은닉 노드: \(h_1, h_2\) | 출력 노드: \(y_1, y_2\) | 정답: \(t_1, t_2\)
  • 손실함수: \(L = \frac{1}{2} \left[ (y_1 - t_1)^2 + (y_2 - t_2)^2 \right]\)
  • 손실 편미분: \(\frac{\partial L}{\partial y_1} = (y_1 - t_1), \quad \frac{\partial L}{\partial y_2} = (y_2 - t_2)\)
  • 항등 활성화 함수 전제: \(f(z) = z \implies f'(z) = 1\)

2) 역전파 연쇄법칙(Chain Rule) 2대 유형

유형 1: 출력층 가중치 편미분 (예: \(w_{35}\))

\(w_{35}\)는 출력 노드 \(y_1\) 하나로만 연결되므로 직렬 연쇄법칙을 적용합니다:

\(\frac{\partial L}{\partial w_{35}} = \frac{\partial L}{\partial y_1} \cdot \frac{\partial y_1}{\partial z_3} \cdot \frac{\partial z_3}{\partial w_{35}} = (y_1 - t_1) \cdot 1 \cdot h_1\)

유형 2: 은닉층 가중치 편미분 (예: \(w_{13}\) 또는 \(w_{23}\)) - 합산 경로

은닉 노드 \(h_1\)은 순전파 시 출력 노드 \(y_1\)과 \(y_2\) 양쪽으로 분기하므로, 역전파 시 두 출력 노드에서 되돌아오는 오차 기울기를 반드시 합산해야 합니다:

\(\frac{\partial L}{\partial w_{13}} = \frac{\partial L}{\partial h_1} \cdot \frac{\partial h_1}{\partial z_1} \cdot \frac{\partial z_1}{\partial w_{13}} = \left( \frac{\partial L}{\partial h_1} \right) \cdot 1 \cdot x_1\) \(\text{단, } \frac{\partial L}{\partial h_1} = \underbrace{\left( \frac{\partial L}{\partial y_1} \cdot 1 \cdot w_{35} \right)}_{y_1 \text{을 거친 역전파}} + \underbrace{\left( \frac{\partial L}{\partial y_2} \cdot 1 \cdot w_{36} \right)}_{y_2 \text{를 거친 역전파}}\)

📌 6주차: 합성곱 신경망 (CNN) & 파라미터 수 계산

1) CNN 커널 연산 및 Feature Map 크기 공식

  • Cross-Correlation: 딥러닝에서는 커널을 180도 뒤집지 않고 원본 커널과 수용영역의 원소별 곱(Element-wise)의 합산에 편향 \(b\)를 가산합니다.
  • 출력 Feature Map Shape 계산:
    \(H_{\text{out}} = \left\lfloor \frac{H_{\text{in}} - K_h + 2P}{S} \right\rfloor + 1, \quad W_{\text{out}} = \left\lfloor \frac{W_{\text{in}} - K_w + 2P}{S} \right\rfloor + 1\)

2) 학습 가능한 파라미터 수 계산 (`bias=True` 기준)

레이어 모듈 파라미터 수 공식 해설 및 예시
nn.Linear(in, out) (in × out) + out • 가중치: \(\text{in} \times \text{out}\)
• 편향: 출력 노드당 1개씩 총 \(\text{out}\)개
예: Linear(64, 6) \(\rightarrow 390\)개
nn.Conv2d(C_in, C_out, K) C_out × (C_in × K_h × K_w + 1) • 필터 1개가 입력 채널 전체(\(C_{\text{in}}\)) 처리
• 필터 1개당 편향 1개 추가
예: Conv2d(1, 4, 3) \(\rightarrow 40\)개
nn.MaxPool2d / AvgPool2d 0 개 단순 최댓값/평균값 추출 연산으로 파라미터 없음
nn.Flatten / nn.ReLU 0 개 텐서 차원 변경 및 활성화 연산만 수행하므로 파라미터 없음

3) 모델 일반화 (Generalization) & 과적합 방지 기법

  • 과적합 (Overfitting): 훈련 데이터에 과도하게 맞춰져 훈련 손실은 매우 낮으나, 새로운 테스트 데이터에 대한 일반화 오차가 커지는 현상.
  • 과소적합 (Underfitting): 모델의 복잡도(용량)가 너무 부족하여 훈련 데이터의 기본 패턴조차 학습하지 못한 현상.
  • 규제화 기법 (Regularization):
    • 드롭아웃 (Dropout): 학습 시 무작위로 일부 뉴런을 비활성화하여 특정 뉴런에 대한 과도한 의존을 차단.
    • 가중치 감쇠 (Weight Decay): 손실함수에 가중치 제곱합(\(L_2\) 규제)을 더해 가중치가 비정상적으로 커지는 것을 억제.
